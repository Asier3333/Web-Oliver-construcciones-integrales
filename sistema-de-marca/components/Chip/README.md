# Chip

Etiqueta en píldora de cristal para el antetítulo de una sección o un dato corto sobre el hero.

Marcado: `<span class="wp-chip"><span class="wp-chip__punto"></span>Clientes Fundadores · 10 plazas</span>`. Tú pones el texto; el punto azul es opcional y solo va en un chip por pantalla.

- `wp-chip` (cristal) sobre un halo o una imagen; `wp-chip--velo` (teñido de `azul-velo`, texto `azul-texto`) sobre fondo liso y como antetítulo de sección.
- De dos a cinco palabras, estilo `etiqueta`, sin mayúsculas sostenidas. Separa datos con « · ».
- No es un botón: si se puede pulsar, usa `wp-btn--s`.
