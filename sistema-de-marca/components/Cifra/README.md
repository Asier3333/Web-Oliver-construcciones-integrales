# Cifra

Número grande con una línea de explicación, para los datos que sostienen la oferta.

Marcado: `<div class="wp-cifra"><span class="wp-cifra__valor">7<small>días</small></span><span class="wp-cifra__pie">De tus recursos a la web publicada</span></div>`. Tú pones el número, la unidad (en `<small>`) y el pie.

- Solo cifras reales y comprobables. Si no hay dato, no hay cifra.
- Filas de dos a cuatro, separadas del contenido anterior por un filete `linea`.
- El valor va en `tinta`, nunca en azul.
- El pie cabe en una línea.
