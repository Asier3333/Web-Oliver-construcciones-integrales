# Hero

Composición de referencia de una página: hero en negro con halo y cristal, seguido de una sección clara con tarjetas y cifras.

Muestra cómo se combinan las piezas y el reparto de color; cópiala como punto de partida, no como plantilla fija. Tú pones titular, entradilla, las dos acciones y las piezas de cristal.

- Hero: sección `data-theme="oscuro"`, `Nav` arriba, `Chip` + `titular-xl` + `entradilla` centrados, un `wp-btn--primario` y un `wp-btn--texto`.
- Un `wp-halo` grande saliendo por abajo; dos piezas de `Cristal` flotando sobre él con datos reales del proceso.
- `Punto` asomado a una de las piezas, señalando hacia el CTA.
- Después, sección clara: `wp-chip--velo`, `titular-l`, rejilla de `Tarjeta` y fila de `Cifra`.
- El botón del nav es `--solido` porque el hero ya tiene el primario.
