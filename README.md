# Web y Punto · Web 2026

Web de Web y Punto (diseño web para PYMES): Home, Oferta Clientes Fundadores, Nuestros proyectos, Equipo, Contacto, Política de privacidad y Términos y condiciones, en español e inglés.

- `index.html`: la web completa en un solo archivo. Se abre con doble clic o se publica tal cual en cualquier alojamiento.
- `fuente/`: las piezas de cada página. Tras editarlas, `python3 construir.py` regenera `index.html`.
- `marca/`, `recursos/`, `sistema-de-marca/`: tokens, tipografía, logos, poses de Punto y sistema de marca.

Detalles, datos editables y pendientes en [LEEME.txt](LEEME.txt).
